## 개인별 탐구

각자의 주제·질문·지금 관심을 가진 이유·참고 자료·개인 기록 경로를 적습니다. 공통 주제를 정하거나 분야별로 항목을 채울 필요는 없습니다. 탐구 중 질문을 바꾸거나 이전 회차의 주제를 이어가도 됩니다.

| 참여자 | 주제와 질문 | 왜 지금 살펴볼 가치가 있는가 | 자료 / 개인 기록 |
|---|---|---|---|
| 미정 | 미정 | 미정 | 작성 후 연결 |

## 모임 진행

개인별 관심 배경과 질문 → 알아보거나 직접 해본 내용과 근거 → 발견과 남은 질문 → 근거와 해석 토론 → 다음 탐구 공유.

서로 다른 주제를 가져와도 처음 접하는 사람이 이해할 수 있도록 배경부터 설명합니다. 눈에 띈 소식은 짧게 나누고, 더 궁금한 것은 이후 탐구로 이어갈 수 있습니다.

## 준비할 것

관심을 가진 이유, 알아보거나 직접 해본 내용과 근거, 발견과 남은 질문을 짧게 남깁니다. 발표 자료나 구현은 필수가 아닙니다. 다른 사람의 해석에 맞추기보다 자기 생각을 먼저 기록합니다. 미완성이라면 확인한 범위와 막힌 이유를 공유합니다.
