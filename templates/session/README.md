## 이 도구를 선택한 이유

어떤 도구이며, 왜 지금 함께 살펴보고 싶은지 적습니다.

## 탐구 목적

이번에 얻고 싶은 경험이나 이해를 간단히 적습니다. 동일한 실습 과제나 하나의 공통 질문을 필수로 두지 않습니다.

## 개인별 탐구

각자의 사용 목적·궁금한 부분·개인 기록 경로를 적습니다. 직접 써본 뒤 탐구 방향을 바꿔도 됩니다.

## 모임 진행

개인별 사용 경험과 해석 공유 → 같은 도구를 다르게 본 이유와 근거 토론 → 공통 발견과 의견 차이 기록 → 탐구 연장 또는 다음 도구 논의.

## 준비할 것

직접 해본 일, 확인한 증거, 자신의 해석, 남은 질문을 짧게 남깁니다. 다른 사람의 해석에 맞추기보다 자기 생각을 먼저 기록합니다. 미완성이라면 확인한 범위와 막힌 이유를 공유합니다.
