# AI Frontier — 회차 주제

- 탐구 단계: 공통 도구 탐구 / 개인별 자율 탐구 중 선택
- 탐구 기간: 미정
- 모임 날짜: 미정
- 회차: 미정
- 참여자: 미정
- 기록 담당자: 미정
- 개인 준비 시간 범위: 모임에서 합의

## 탐구 도구와 선정 이유

초반에는 공통 도구 하나와 공식 저장소 링크, 선정 이유를 적습니다. 이후에는 개인별 선택 도구·공식 저장소 링크·관심을 가진 이유를 적습니다.

## 탐구 목적

이번에 얻고 싶은 경험이나 이해를 간단히 적습니다. 동일한 실습 과제나 하나의 공통 질문을 필수로 두지 않습니다.

## 개인별 탐구

각자의 도구·사용 목적·궁금한 부분·개인 기록 경로를 적습니다. 직접 써본 뒤 탐구 방향을 바꿔도 됩니다.

## 모임 진행

개인별 오픈소스 설명 → 직접 경험과 증거 공유 → 현재 AI 생태계에 대한 개인 관점 설명 → 관찰과 근거 토론 → 발견과 의견 차이 기록 → 다음 탐구 공유.

초반에는 같은 도구에 대한 관점의 차이를 살펴봅니다. 개인별 자율 탐구 단계에서는 각 프로젝트의 배경부터 설명하고, 서로 다른 프로젝트에서 읽을 수 있는 생태계의 흐름을 나눕니다.

## 준비할 것

처음 접하는 사람을 위한 오픈소스 설명, 직접 경험과 증거, 현재 AI 생태계에 대한 자신의 생각과 그 이유, 남은 질문을 짧게 남깁니다. 다른 사람의 해석에 맞추기보다 자기 생각을 먼저 기록합니다. 미완성이라면 확인한 범위와 막힌 이유를 공유합니다.
