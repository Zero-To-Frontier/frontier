# 개인 탐구 기록

형식은 자유입니다. 다음 세 항목을 짧은 메모와 근거 링크로 남겨도 충분합니다.

## 무엇이 궁금했고, 왜 지금 살펴볼 가치가 있는가

주제와 처음 궁금했던 질문, 관심을 가진 이유를 적습니다. 오픈소스·논문·제품·산업·사회 변화 등 대상은 자유롭게 선택합니다.

## 무엇을 알아보거나 직접 해봤는가

처음 접하는 사람도 이해할 수 있도록 배경과 핵심 내용을 자신의 말로 설명합니다. 살펴본 자료나 직접 해본 일, 발견을 뒷받침하는 근거를 연결합니다.

- 자료 조사라면 출처·날짜·주요 주장과 확인한 범위를 남깁니다.
- 사용이나 실험을 했다면 도구·버전·실행 조건과 코드·로그·데모 등을 필요한 만큼 남깁니다.

위 방법을 모두 수행할 필요는 없습니다. 직접 확인한 사실과 자료의 주장을 구분하고, 확인하지 못한 부분은 미검증으로 남깁니다.

## 무엇을 발견했고, 무엇을 함께 이야기하고 싶은가

새로운 가능성·한계·변화에 대한 생각과 그 이유, 예상과 달랐던 점, 남은 질문을 적습니다. 다음은 생각을 돕는 예시이며 모두 답할 필요는 없습니다.

- 왜 지금 주목받고 있으며 실제로 어떤 가치가 있는가?
- 어떤 조건에서 가능하고, 어디에서 한계가 드러나는가?
- 기술적으로 가능한 것과 실제 현장의 변화 사이에는 어떤 차이가 있는가?
- 어떤 업무를 대체하거나 보조하며, 사람의 역할은 어떻게 달라지는가?
- 산업이나 일상에서 이미 확인된 변화는 무엇인가?
- 탐구 전후로 내 생각은 어떻게 바뀌었는가?

사실과 개인의 해석, 이미 확인된 변화와 앞으로의 전망을 구분합니다. 결론이 잠정적이거나 실험이 실패해도 확인한 범위와 남은 질문을 공유합니다.
