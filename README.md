# AI Frontier

Frontier는 AI의 최전선에서 일어나는 변화를 탐구하는 모임입니다.

오픈소스, 논문, 제품, 산업과 사회의 변화 속에서 지금 살펴볼 가치가 있는 주제를 각자 선택합니다. 자료와 직접 경험을 바탕으로 새로운 가능성과 한계를 확인하고, 그 의미와 남은 질문을 나눕니다.

Zero-To-Frontier는 변화의 방향을 탐색하는 Frontier와 오래가는 원리를 연구하는 Zero를 함께 운영합니다. 두 트랙은 각자의 흐름으로 진행하며, 주제를 매번 연결할 필요는 없습니다.

## 탐구 방향

최전선은 단순히 가장 최근에 나온 것만을 뜻하지 않습니다. 새로운 가능성이 열리거나, 한계가 드러나거나, 실제 변화가 시작되는 지점을 살펴봅니다. 주제를 고르는 공통 기준은 **“왜 지금 이것을 살펴볼 가치가 있는가?”**입니다.

매 회차 공통 주제나 분야를 정하지 않고, 처음부터 각자가 관심 있는 질문과 대상을 선택합니다. 다음은 탐구 대상의 예시이며, 회차마다 모두 다루거나 순서대로 채울 항목은 아닙니다.

- **오픈소스:** 새로운 가능성을 보여주는 프로젝트, 해결하려는 문제, 구조와 사용 경험
- **논문:** 새로운 접근과 연구 결과, 주장을 뒷받침하는 근거와 한계
- **제품과 최신 흐름:** 주목받는 모델·서비스·기업, 관심을 받는 이유와 실제 활용 가치
- **산업과 일:** 개발을 포함한 다양한 산업의 업무 변화, AI가 대체하거나 보조할 수 있는 일과 도입 조건
- **사회와 생활:** 교육·창작·정보 소비·일자리 등에서 이미 나타난 변화와 앞으로의 질문

논문 읽기, 오픈소스 사용과 코드 분석, 제품 체험, 현장 사례 조사, 직접 만들고 실험하기 등 질문에 맞는 방법을 선택합니다. 오픈소스는 중요한 탐구 대상이며, 관심이 있으면 내부 구현까지 깊게 살펴볼 수 있습니다. 탐구 범위를 개발이나 특정 자료 형식으로 제한하지 않습니다.

한 번에 작은 질문 하나부터 시작하고, 필요하면 여러 회차 이어갑니다. 함께 탐구하고 싶은 주제가 생기면 자율적으로 공통 탐구를 진행할 수 있습니다.

## 공유할 것: 질문, 근거, 발견

자유롭게 고르되, 듣는 사람에게 발견 하나를 가져옵니다. 짧은 메모와 자료 링크로 다음 내용을 나눠도 충분합니다.

1. **왜 관심이 생겼는가:** 무엇이 궁금했고, 왜 지금 살펴볼 가치가 있다고 생각했는지 설명합니다.
2. **무엇을 알아보거나 해봤는가:** 처음 접하는 사람도 이해할 수 있도록 배경을 설명하고, 살펴본 자료나 직접 확인한 경험과 근거를 공유합니다.
3. **무엇을 발견했고 무엇이 남았는가:** 새로운 가능성·한계·변화에 대한 생각, 탐구 전후 달라진 판단, 함께 이야기하고 싶은 질문을 남깁니다.

결론이 잠정적이거나 실험이 실패해도 됩니다. 매번 구현을 하거나 산업 전체에 대한 전망을 내놓을 필요는 없습니다. 긴 발표 자료보다 자신의 말로 설명할 수 있는 기록을 중시합니다.

## 운영 방식

- 전체 모임은 매주 열고, 홀수 주에는 Zero, 짝수 주에는 Frontier를 진행합니다. Frontier는 2·4·6·8주차처럼 2주마다 돌아옵니다. 실제 시작 날짜와 모임 시간은 별도로 정합니다.
- 각자 탐구할 주제와 관심을 가진 이유를 공유합니다. 같은 회차에 서로 다른 대상을 다뤄도 됩니다. 공통 주제나 분야별 순환을 필수로 두지 않습니다.
- 공유 일정과 준비 시간은 함께 정합니다. 탐구 중 질문을 바꾸거나 같은 주제를 여러 회차 이어갈 수 있습니다.
- 학습은 `sessions/번호-exploration/`으로 관리합니다. 세션은 약 2주간의 학습 단위이고, 실제 미팅은 그 안의 `meetings/날짜-종류.md`로 기록합니다.
- 개인 기록과 코드는 세션 폴더 안의 자기 이름 폴더에 남깁니다.
- 세션 안내와 회의록은 그 회차의 기록 담당자가 반영합니다. 담당자는 돌아가며 맡습니다.
- 발표 자료는 필수가 아닙니다. 알아보거나 직접 해본 일, 확인한 근거, 자신의 해석, 남은 질문을 짧게 준비합니다. 모든 항목을 긴 보고서로 작성할 필요는 없습니다.
- 모임 전에는 각자의 생각을 먼저 기록합니다. 모임에서는 개인별 탐구의 배경과 발견을 공유하고 근거와 해석을 토론합니다. 눈에 띈 최신 소식은 짧게 나누고, 더 궁금한 것은 이후 탐구로 이어갈 수 있습니다. 공동 기록에는 확인한 사실·서로 다른 해석·미해결 사항·다음 질문을 남기며, 하나의 결론으로 의견을 맞출 필요는 없습니다.
- 세션 폴더를 진행과 기록의 기준으로 사용합니다. Issues와 Projects는 필요할 때 도입합니다.

## 탐구 기준

1. 왜 지금 이 주제를 살펴볼 가치가 있는지, 어떤 가능성·한계·변화와 맞닿아 있는지 생각합니다. 유명세나 최신성만으로 선택하지 않습니다.
2. 질문에 맞는 자료와 방법을 선택하고, 무엇을 알아보거나 해봤는지 근거와 함께 남깁니다. 직접 사용하지 않았다면 자료로 확인한 범위를 밝힙니다.
3. 직접 관찰한 사실, 자료의 주장, 개인의 해석을 구분합니다. 이미 확인된 변화와 앞으로의 전망도 구분하며, 확인하지 못한 부분은 미검증으로 남깁니다.
4. 기술적으로 가능한 것과 현장에 실제로 도입되어 달라진 것을 구분합니다. 업무의 대체를 다룰 때는 구체적인 작업과 조건부터 살펴보고, 한 사례로 직업이나 산업 전체를 단정하지 않습니다.
5. 탐구 범위와 깊이는 개인이 선택합니다. 발견과 남은 질문이 생겼다면 다른 주제로 넘어가거나 더 탐구할 수 있습니다.

최신 소식 요약이나 기능 소개에 그치지 않고, 작은 발견을 누적하며 이전 판단을 돌아봅니다.
