# AI Frontier

AI 산업의 변화와 그에 따라 등장하는 오픈소스·도구를 살펴보며, 현재 생태계의 방향에 대한 관점과 질문을 쌓습니다.

Zero-To-Frontier는 변화의 방향을 탐색하는 Frontier와 오래가는 원리를 연구하는 Zero를 함께 운영합니다. 두 트랙은 각자의 흐름으로 진행하며, 주제를 매번 연결할 필요는 없습니다.

## 탐구 방향

초반에는 공통 도구를 각자 독립적으로 사용하고 탐구하며 기본 감각을 쌓습니다. 이후에는 각자 관심 있는, 새롭게 주목받는 오픈소스를 선택해 탐구하고 경험과 관점을 공유하며 생태계에 대한 시야를 넓힙니다.

- 초반 약 한 달은 주요 오픈소스·도구를 공통으로 하나씩 정해 탐구하며 기본 개념과 생태계를 보는 기준을 만듭니다.
- 이후에는 각자 관심 있는, 새롭게 주목받는 오픈소스를 선택해 탐구합니다. 같은 회차에 서로 다른 도구를 다룰 수 있습니다.
- 사용 목적·질문·접근 방법·탐구 깊이는 처음부터 개인이 선택합니다. 기반이 잡힌 뒤에는 탐구할 도구의 선택까지 자율로 확장합니다.
- 여러 도구를 동시에 비교하는 과제나 동일한 실습 과제를 필수로 두지 않습니다. 경험이 쌓이면 이전 도구와의 차이를 자연스럽게 돌아봅니다.

## 운영 방식

- 2주 동안 탐구하고 결과를 공유하며, Frontier와 Zero를 교차 진행하는 방식을 기본안으로 둡니다. 도입 기간의 실제 일정·회차 수·준비 시간은 별도로 합의합니다. 초반 약 한 달의 탐색 방향만 정하며, Frontier에만 집중하는 일정으로 확정한 것은 아닙니다.
- 초반에는 공통 도구 하나를 정하고, 이후에는 각자가 탐구할 도구와 선정 이유를 공유합니다. 공유 일정은 함께 정하며, 필요하면 각자의 도구를 여러 회차 이어갑니다.
- 각 회차는 저장소 루트의 `YYYYMMDD/` 폴더로 관리합니다. 날짜는 결과를 공유하는 모임 날짜를 사용합니다.
- 개인 기록과 코드는 회차 폴더 안의 자기 이름 폴더에 남깁니다.
- 회차 안내와 회의록은 그 회차의 기록 담당자가 반영합니다. 담당자는 돌아가며 맡습니다.
- 발표 자료는 필수가 아닙니다. 직접 해본 일, 확인한 증거, 자신의 해석, 남은 질문을 짧게 준비합니다. 모든 항목을 긴 보고서로 작성할 필요는 없습니다.
- 모임 전에는 각자의 생각을 먼저 기록합니다. 초반 모임에서는 같은 도구에 대한 관점의 차이를 나눕니다. 이후에는 각자 탐구한 프로젝트의 배경과 경험을 공유하고, 서로 다른 프로젝트에서 발견되는 문제의식과 변화의 흐름을 함께 생각합니다. 공동 기록에는 확인한 사실·서로 다른 해석·미해결 사항·다음 질문을 남기며, 하나의 결론으로 의견을 맞출 필요는 없습니다.
- 회차 폴더를 진행과 기록의 기준으로 사용합니다. Issues와 Projects는 필요할 때 도입합니다.

## 폴더 구조

아래 날짜와 이름은 구조를 설명하는 예시이며, 실제 회차 일정과 참여자를 확정한 것은 아닙니다.

```text
YYYYMMDD/
├── README.md        # 탐구 단계·도구 목록·일정
├── 윤호/
│   └── README.md    # 개인 기록과 실험 코드
├── 동민/
│   └── README.md
└── meeting.md       # 공동 회의록과 결론
```

## 탐구 기준

1. 직접 사용하며 어떤 사용자와 문제를 위한 도구인지 살펴봅니다.
2. 사용 중 생긴 질문을 바탕으로 관심 있는 구조·설계 선택·사용성·한계를 탐구합니다. 역할과 세부 주제를 처음부터 고정하지 않습니다.
3. 무엇을 해봤고 무엇을 발견했는지 근거와 함께 남기고, 도구가 지향하는 방향에 대한 자기 생각을 정리합니다.
4. 프로젝트가 생태계의 어느 영역에 속하는지 살펴봅니다. 한 도구의 특징으로 AI 산업 전체를 단정하지 않습니다.
5. 직접 관찰한 사실, 자료의 주장, 개인의 해석을 구분합니다. 실행하지 못한 부분은 미검증으로 남깁니다.

도구의 모든 내부 구현을 분석할 필요는 없습니다. 해결하려는 문제와 핵심 사용 경험을 설명하고, 장점·한계·남은 질문이 생겼다면 다음 도구로 넘어갈 수 있습니다. 더 확인할 가치가 있는 질문이 있으면 탐구를 연장합니다.

최신 소식 요약이나 기능 소개에 그치지 않고 작은 관찰을 누적하며, 생태계에 대한 이전 판단을 수정합니다.
